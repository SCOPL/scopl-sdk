# Security policy

The SCOPL SDK constructs and validates transaction plans that may be signed by
user wallets. Do not report a suspected vulnerability in a public issue or
disclose an exploit before the maintainers have had time to respond.

Use the repository's private GitHub security-advisory channel. Include the
affected SDK version and method, impact, prerequisites, reproduction steps,
and any proposed mitigation. Never include private keys, seed phrases, paid
RPC credentials, or other secrets in a report.

There is currently no public bug-bounty promise. Acknowledgement or payment
must not be assumed without a separate written agreement.
